📊 DATABASE SCHEMA (8 Tables):

  pigs
    ├─ id, game_id, player_id
    ├─ name, age_in_days, birth_date, skin
    ├─ personality, favorite_snack
    ├─ job, workplace_id, happiness_level
    ├─ earnings_total, earnings_today, treats_received
    ├─ home_building_id, owned_furniture
    ├─ stocks_owned, investment_total
    ├─ is_married, spouse_id, family_members, offspring
    ├─ health_status, last_fed, last_watered
    └─ created_at, updated_at, last_activity

  pig_work_log (tracks every shift)
    ├─ pig_id, workplace_type, shift_start/end
    ├─ earnings, customers_served, efficiency_percent
    └─ shift_mood

  pig_care_log (tracks all care)
    ├─ care_type (fed, watered, petted, treat, etc.)
    ├─ pig_happiness_before/after
    └─ recorded_at

  pig_achievements (milestones)
    ├─ achievement_type (promotion, birthday, marriage, etc.)
    ├─ title, description, reward_coins
    └─ achieved_at

  pig_health_log (health history)
    ├─ health_status, condition, treatment_given
    └─ treatment_effective

  pig_genealogy (family trees)
    ├─ parent_1_id, parent_2_id, generation
    └─ breed_characteristics

  pig_building_relationships (home/work)
    ├─ building_game_id, relationship_type
    ├─ (home, workplace, visited)
    └─ start_date, end_date

  pig_statistics_history (trends)
    ├─ Snapshot of all stats at point in time
    └─ snapshot_date

🚀 QUICK START (3 Steps):

  STEP 1: Apply Database Migration
  ────────────────────────────────
    1. Go to Supabase Console
    2. SQL Editor → New Query
    3. Paste: supabase/migrations/20261110000000_pig_tracking.sql
    4. Click Run
    ✅ Database ready!

  STEP 2: Add Scripts to HTML
  ──────────────────────────
    In index.html, after supabase script:
    
    <script src="pig-database.js"></script>
    <script src="pig-database-integration.js"></script>
    ✅ Scripts loaded!

  STEP 3: Initialize & Use
  ──────────────────────
    In account-system.js:
    
    window.pigDatabaseIntegration.init(supabaseClient);
    
    Then in game code:
    
    await window.pigDatabaseIntegration.onShiftCompleted(
      pigId, 'cafe', 50, 5, gameId, playerId
    );
    ✅ Tracking working!
